# Graphify

Graphify is reserved for structural understanding of source repositories.

## Intended responsibility
- index repositories
- extract code relationships
- expose graph/context to agents
- support repository-aware reasoning

## Non-responsibility
It does not replace Git/GitHub.

## Initial status
Documented, not installed.

## Later work
Before installation, verify current upstream requirements, persistence backend, incremental reindexing, rebuild process, and disk footprint.
